# Barlow Condensed

`BarlowCondensed-ExtraBold.ttf` is the unmodified ExtraBold face from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlowcondensed),
retrieved 5 November 2026. It is bundled for consistent offline video rendering.
The accompanying `OFL-BarlowCondensed.txt` contains its SIL Open Font License.
